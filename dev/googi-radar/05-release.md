## 주소
- 서비스: **https://googi-radar.vercel.app**
- 로컬 개발: http://localhost:3000 (`python -m http.server 3000 --directory app`)
- 배포 날짜: 2026-11-10 (사용자 선택: Vercel, 무료 Hobby 플랜)

## 배포 방법과 다시 배포하는 법
- 방식: Vercel CLI로 `app/` 폴더를 직접 올림 (GitHub 연결 안 함 → `config.js`를 git에 넣지 않아도 됨).
- 다시 배포: 프로젝트 폴더에서
  ```
  cd app
  npx vercel@65.14.0 deploy --prod --yes --name googi-radar
  ```
  - 처음이거나 로그인이 풀렸으면 먼저 `npx vercel@65.14.0 login`.
  - `app/.vercelignore`: `tests/`는 올리지 않음.
- 배포 설정 `app/vercel.json`: 보안 헤더
  - CSP(카카오 주소도 `https:`만, `frame-ancestors 'none'`, `upgrade-insecure-requests`)
  - X-Frame-Options DENY, X-Content-Type-Options nosniff, Referrer-Policy, Permissions-Policy(위치는 이 사이트만, 카메라·마이크·결제 끔)
  - HSTS는 Vercel이 자동으로 붙임(확인함)
- 배포 뒤 확인(2026-11-10, Chrome 헤드리스·curl):
  - `/` 200, `/tests/…` 404(안 올라감), 보안 헤더 6개 확인
  - 공개 파일 `config.js`에 비밀 키 없음(걸린 2건은 "넣지 마세요" 설명 주석)
  - 주안역 주변 지도 핀 61개, 넓히면 86개, 가격 핀 3개(심정·삼겹식당 인천신기점·돼슐랭 주안점) → 카카오 도메인 등록과 DB 연결 정상
  - 보안 점검 스크립트 15개 통과

## 키 관리
| 키 | 종류 | 있는 곳 | 바꾸는 법 |
|---|---|---|---|
| 카카오 JavaScript 키 | 공개용 | `app/config.js`(git 제외) → 배포된 config.js | 카카오 개발자 > 앱 > [플랫폼 키] > JavaScript 키 재발급 → config.js 고치고 다시 배포 |
| Supabase Project URL | 공개용 | 같음 | 바뀌지 않음(프로젝트를 새로 만들 때만) |
| Supabase Publishable key | 공개용 | 같음 | Supabase > Project Settings > API Keys에서 새 키 만들기 → config.js 고치고 다시 배포 → 옛 키 삭제 |
| Supabase Secret key, DB 비밀번호 | **비밀** | 어디에도 넣지 않음(비밀번호 관리 앱에만) | 새어 나갔다고 생각되면 바로 재발급 |
| 운영자 계정 비밀번호 | **비밀** | 본인만 | Supabase > Authentication > Users에서 바꾸기 |

- 카카오 **JavaScript SDK 도메인** 등록 목록: `http://localhost:3000`, `https://googi-radar.vercel.app`. 주소를 바꾸거나 새 도메인을 붙이면 여기에 추가해야 지도가 뜸.
- 공개용 키가 보여도 괜찮은 이유: 카카오는 등록한 도메인에서만, Supabase는 DB 규칙(RLS)으로 운영자만 쓰기 가능.
- 2단계 인증 권장: Vercel(설정함), Supabase, GitHub, 카카오 계정.

## 데이터 백업
- Supabase 무료 플랜은 백업 파일을 받을 수 없다. 직접 받아 둔다(월 1번, 많이 입력한 날).
  1. **표 내려받기(쉬움):** Table Editor > `stores` > 오른쪽 위 Export(또는 ⋯) > **Export to CSV**. `menus`도 같이.
  2. **SQL로 한 번에:** SQL Editor에서 `select * from public.stores;`, `select * from public.menus;` 실행 → 결과를 CSV로 내려받기.
- 메뉴판 사진: Storage > `menu-photos`에서 내려받기.
- 표 구조는 `dev/googi-radar/sql/01·05·06`으로 다시 만들 수 있다(운영자 등록은 04).

## 무료 한도와 넘으면 생기는 일
| 서비스 | 무료 한도 | 넘거나 문제가 생기면 |
|---|---|---|
| Vercel Hobby | 월 100GB 전송, **비상업 용도만** | 한도를 넘으면 그 달 배포가 멈출 수 있음. 광고·유료 기능을 넣으면 Pro(월 20달러) 필요 |
| Supabase Free | DB 500MB, 파일 1GB, **7일 동안 요청이 없으면 일시 정지** | 정지되면 사이트에 "가격 정보를 불러오지 못했어요"가 뜨고 지도의 고기집만 보임. Supabase 대시보드에서 프로젝트 **Restore**를 누르면 돌아옴(데이터 유지) |
| 카카오 로컬 API | 키워드 검색 하루 약 10만 회(첫 활성 앱 기준) | 넘으면 "지금은 가게 목록을 불러올 수 없어요" + 저장된 가게만 목록으로. 지도를 한 번 옮길 때 최대 10회 호출 |
| 카카오 지도 | 하루 약 30만 회 | 넘으면 지도가 안 뜸 |

## 성공 지표 재는 법 (기획 6장)
- **상권별 데이터 확보 수(G2, 목표 주안 20곳·구월 20곳):** 운영자 화면 아래 "중량 표기 비율"이 상권별로 "확인한 n곳 중 m곳"을 보여 준다. m이 100g당 가격을 계산할 수 있는 가게 수. 2026-11-10 현재 10곳 입력(모두 주안).
- **메뉴판 중량 표기 비율(G3):** 같은 칸의 % 값. 50% 미만이면 방식 재검토(D28-10).
- **본인 사용 횟수(G1·G4, 2달 동안 3번 이상):** 서비스가 기록하지 않음(방문 기록을 저장하지 않는 결정 D23). 고기 먹으러 갈 때 이 서비스로 가게를 고르면 날짜와 가게를 메모 앱에 적는다.
- **확장 판단(G4):** 사용 시작 후 2달(2027-01 중순) 위 지표로 결정.

## 남은 이슈
### 검증에서 넘어온 것 (04-verify 2차 리뷰, 고치지 않음)
- 키·도메인이 잘못됐을 때도 "인터넷 연결 확인"으로 안내됨(로그인 "Invalid API key"는 "비밀번호가 맞지 않아요"로 보임).
- 사진 업로드 단계가 예외를 던지면 메뉴는 저장됐는데 "저장하지 못했어요"가 뜰 수 있음.
- 비동기 순서: 연달아 검색, 위치 응답이 늦게 와서 고른 동네를 덮음, 입력한 가게 목록·즐겨찾기 늦은 응답.
- 작은 것: 알림 연달아 띄울 때 바로 지워질 수 있음, 카카오 오류 상태의 동네 버튼, 저장 중 예외 시 버튼이 계속 막힘, 가격 없이 넣은 중량이 버려짐, 사진 불러오기 실패 고정, DB 거부 사유(22023 등) 안내, 메뉴별 계산 타이머, 시트 끌기 pointer capture, 카카오 오류 때 남은 핀, 오늘 날짜를 처음 연 순간으로 고정, 같은 "다시 불러오기" 버튼 2개.
- 보안(낮음): 01-schema.sql 79줄과 06의 photo_path 권한 맞추기, 트리거 함수 권한 정리, 글꼴 CSS SRI.
