## 0. 개요
- **무엇:** 인천 주안역·구월동 고기집의 삼겹살·목살을 **100g당 가격**으로 비교하는 모바일 웹. 가격 데이터는 운영자(본인)가 메뉴판을 보고 입력한다.
- **누가, 어떻게:** 고기 먹으러 가기 전에 폰으로 주변 가게를 비교하고(지도·목록 → 최대 3곳 비교), 맛은 카카오맵 리뷰로 판단한다. [기획 D1, D5, D9]
- **시각 콘셉트:** 정육점 가격표 라벨(중량 | 100g당 | 판매가) + 비교 화면의 시세 막대. 눈에 띄는 것은 100g당 숫자 하나. [01]

## 3. 레이아웃
- 폰 기준. 콘텐츠 최대 폭 **480px**, 가운데 정렬, 좌우 여백 `s4`(16px).
- 세로 구조: 앱바(제목 + 지도 화면에서만 위치) → 화면 본문(main) → 하단 탭바(sticky, safe-area 포함).
- ① 지도·목록: 필터(부위/종류/원산지 3줄) → 지도(높이 260px) → 핀 정보 패널(핀을 눌렀을 때, 지도 **아래**) → "100g당 싼 순" 목록 → "중량 미표기" 묶음.
- ② 비교: 고기·기준 선택 → 비교 표(가로 스크롤 가능) → 시세 막대 → 이득 문장 → [+ 가게 추가] → 추가 목록.
- 왼쪽 정렬이 기본. 빈 화면 안내만 가운데 정렬.

## 6. 계산 규칙 (정답 코드: app.js)
| 규칙 | 내용 | 근거 |
|---|---|---|
| 100g당 가격 | 1인분 가격 ÷ 중량 × 100, 또는 메뉴판 100g당 가격. 둘 다 있고 10원 이상 다르면 계산값 사용 + 불일치 안내 | R3, D17, D26-10, Q2(임시) |
| 계산 vs 표시 | 계산은 반올림 전 값, 표시만 원 단위 반올림 | R3 |
| 순위 | 가게 단위, 조건(부위·종류·원산지)에 맞는 메뉴 중 100g당 최저가. 숙성 메뉴도 같은 종류로 섞임([숙성] 표시) | R4, D24 |
| 중량 미표기 | 순위에서 빼고 목록 맨 아래 묶음(필터 적용). 비교에서는 100g당 "알 수 없음", 가격 기준에는 포함 | R5, D8, D28-3·6 |
| 추천 배지 | (비싼 쪽 − 싼 쪽) ÷ 비싼 쪽 ≥ 3% → [가성비 추천], 미만 → "거의 같아요". 3곳이면 1등과 2등으로 판정 | D20, D28-4 |
| 이득 문장 | 늘어난 g의 가치를 **상대 가게 100g당 가격**으로 계산, 10원 단위 반올림. 3곳이면 가성비 1등 기준으로 나머지 각각 | D21, D26-6·12 |
| 동네 시세 | 비교 가게 좌표 평균에서 반경 1km, 같은 부위·종류·원산지, 가게당 최저가의 중간값. 5곳 미만이거나 비교 가게끼리 2km 넘으면 "-" | R7, D18, D26-5·17, D28-7 |
| 오래된 정보 | 오늘 > 확인일 + 6개월(없는 날은 그 달 말일), 한국 시간 | R10 |
| 입력 조합 | 1인분 가격만 = 중량 미표기, 중량만 = 저장 거부, 100g당 + 1인분 가격 = 100g당 사용 | D26-9 |
| 조사 | 가게 이름 뒤 이/가, 은/는은 받침으로 결정(josa 함수) | copy.md |

## 9. 접근성 고려 사항 (03-a11y 반영 결과)
- **대비:** 모든 글씨 4.5:1 이상(가장 낮은 값 4.86:1), 조작 요소 경계 3:1 이상. 초록 글씨는 흰 상자 안에서만.
- **색만으로 구분하지 않기:** 저렴/비쌈은 ± 기호와 글자, 오류는 "!"와 칸 이름 문구, 핀 종류는 글자와 테두리 모양.
- **키보드:** 모든 조작은 button·a·input·select. 건너뛰기 링크("본문으로 건너뛰기"). 다시 그린 뒤 포커스 복원.
- **포커스 순서:** 앱바(뒤로) → 필터 → 지도 핀(데이터 순서) → 핀 패널 → 목록 → 하단 탭.
- **화면 낭독기 라벨:** 지도 영역 "고기집 지도", 핀 "가게, 100g당 ○원" / "가게, 필터 밖: …", 별 "가게 즐겨찾기"(aria-pressed), 순위 "1위", 시세 줄 role=img + 설명, 비교 표 caption과 th scope, 빼기 "가게 비교에서 빼기", 외부 링크 "(새 창)".
- **상태 알림:** 토스트 role=status(닫기 전까지 유지), 로딩 role=status, 계산 줄 aria-live=polite, 저장 결과 role=status/alert.
- **입력:** 모든 칸에 label, 오류 칸 aria-invalid + 칸별 오류 문구 aria-describedby, 실패 시 첫 오류 칸으로 포커스.
- **터치 영역:** 44px 이상(핀 포함). 문서 제목은 화면마다 "비교 - 고기 레이더"처럼 바뀜.

## 12. 실제 서비스로 옮길 때
- 가짜 지도·데이터 → 카카오 지도 JS API + 로컬 API 실시간 검색(대량 저장 금지) [D16]. 가게 저장은 운영자가 입력한 가게의 장소 ID·좌표·메뉴만 [D23, D27, Q9].

- 저장 요청 중 버튼 로딩 상태(미정)를 정해야 한다.
- 기획 열린 질문 Q2(표기 불일치 처리), Q4(참가격 표시), Q9(카카오 약관)는 그대로 열려 있다.
