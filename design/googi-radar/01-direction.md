## 제시한 방향
### A. 정육점 가격표 라벨 (추천)
- 정육점 포장 라벨(중량 / 100g당 / 판매가)을 가게 카드로. 색: 라벨 흰색 #FFFFFF, 정육 빨강 #B3121F, 인쇄 남색 #1D2A44, 스테인리스 회색 #E9EBEE, 보조 회색 #5F6670
- 맞는 이유: "100g당"은 원래 정육점 라벨의 말이라 설명 없이 읽힌다. 위험: 빨강 남용 시 경고처럼 보임
### B. 고깃집 벽 메뉴판
- 흰 아크릴과 시트지 글씨, 아주 큰 숫자. 색: #FAFAF7, #D7262E, #1F4FA3, #FFE14D, #262626
- 맞는 이유: 동네 고깃집의 활기, 숫자가 주인공. 위험: 비교 표·입력 화면에서 시끄러움
### C. 시세 막대
- 지도 크게, 가게마다 동네 시세 대비 위치를 막대로. 색: #F7F8F6, #20242A, #2F7D4F, #B5600F, #8A9099
- 맞는 이유: "동네보다 싼가"를 눈으로 바로. 위험: 흔한 대시보드처럼 보임, 시세 5곳 미만이면 막대가 빔

## 고른 방향
- 선택: **A(정육점 가격표 라벨) + C의 시세 막대** (사용자 선택, 2026-11-10)
- 사용자가 밝힌 이유: 밝히지 않음
- 섞는 방법 (Claude 제안, 이 파일 확인으로 승인받음):
  - 전체 시각 언어는 A. 목록·상세·비교의 가게 정보는 라벨 칸 구조로 보여준다.
  - C의 시세 막대는 **② 비교 화면에만** 넣는다. 동네 시세(03 R7)는 비교하는 가게들을 기준으로 계산하는 값이라 목록에서는 기준점이 없기 때문이다. 동네 시세가 없으면(5곳 미만, 2km 초과) 막대 자리에 "동네 시세: - (비교할 가게가 아직 적어요)"를 보여준다.
  - C의 초록·주황은 막대와 "동네 대비 %"에만 쓴다(저렴 = 초록, 비쌈 = 주황). 다른 곳에는 쓰지 않는다.
- 섞으면서 바꾼 값: C의 비쌈 주황 #B5600F는 흰 배경 대비가 4.52:1로 기준(4.5:1)에 너무 가까워 **#A3540C(약 5.5:1)**로 어둡게 바꿈.

## 지키는 규칙
1. **빨강은 100g당 가격 숫자에만** 쓴다. 버튼, 배지, 제목에는 쓰지 않는다(경고처럼 보이지 않게).
2. **라벨 카드:** 가게 정보는 "중량 | 100g당 | 판매가" 칸으로 나눈 라벨 모양. 칸 나눔 선은 정보 구분일 때만 쓴다.
3. **눈에 띄는 것은 한 곳:** 100g당 숫자(28px 빨강). 나머지는 조용하게 둔다.
4. **시세 막대는 비교 화면에만**, 초록·주황은 막대와 %에만.
5. **배지:** [가성비 추천]·[양 최고]·[가장 저렴]은 남색 테두리의 흰 바탕 라벨(빨강 아님). "거의 같아요"는 회색 테두리.
6. **피할 것:** 모든 제목 위의 작은 라벨, 같은 둥근 카드 묶음과 회색 그림자, 장식용 그라데이션, 버튼 글씨 뒤 화살표, 등장 애니메이션. 움직임은 사용자가 누른 결과를 보여줄 때만(예: 비교에 넣으면 하단 바 숫자 갱신). `prefers-reduced-motion`을 따른다.
7. **문구는 copy.md 그대로.** 열린 질문(Q2 표기 불일치, Q4 참가격, Q9 좌표 저장)은 화면에서 확정처럼 그리지 않는다.

### 글꼴 (외부 글꼴 허용)
- 본문: **Pretendard** v1.3.9 (jsDelivr). 없으면 Apple SD Gothic Neo / 맑은 고딕
- 숫자: **Barlow Condensed** 600~800 (Google Fonts). 좁고 단단한 숫자로 정육점 라벨 느낌. 100g당 숫자 40px 800
- 크기: 글씨 12 / 14 / 16 / 18 / 20, 숫자 전용 22 / 28 / 40
- 주의: 인터넷이 없으면 대체 글꼴로 보인다(외부 요청 5개: 글꼴 CSS 2, preconnect 3)

### 바뀐 규칙
1. 포커스: 어두운 바탕에서는 숯불색 3px, 흰 라벨 안에서는 남색 3px.
2. 주 버튼: 어두운 바탕에서는 숯불색 바탕 + 숯색 글씨, 흰 라벨 안에서는 남색 바탕 + 흰 글씨.
3. 모서리 3px, 그림자는 **떠 있는 것(지도 핀, 알림)에만** 아래로 2~4px 진한 그림자. 카드에는 그림자 없음.
4. 장식 그라데이션은 조명 한 곳만. 라벨 절취 홈과 점선은 "라벨"이라는 정보를 전하는 구조 장치로만 쓴다.
5. 누를 때 1px 눌림(:active). 움직임 줄이기 설정에서는 끔.

### 레이아웃 개편 (2026-11-10, 2차 디자인 리뷰 뒤 사용자 선택)
> 계기: 사용자 "ui가 레이아웃 구조가 너무 별론데". 선택지 3개씩 보여 주고 고름
- **첫 화면:** 지도가 화면 전체, 가격 목록은 **아래에서 끌어올리는 시트**(접힘 112px / 반 54% / 전체). 손잡이를 누르면 다음 높이, 끌면 가까운 높이로 붙음. 필터는 지도 위 **가로 스크롤 칩 한 줄**(부위 | 종류 | 원산지). 핀을 누르면 시트 안에 그 가게 라벨이 나옴(지도를 가리지 않고 화면 밖으로 밀리지 않음). 비교에 담은 가게가 있으면 시트 아래 "비교 n곳 [비교 보기]" 트레이.
- **하단 탭:** 지도·목록 / 비교 / **즐겨찾기**(이 폰에만, R17). **운영자 입력은 앱바 오른쪽 메뉴(⋯) 안으로** 옮김.
- **비교 화면 순서:** 담은 가게 칩(×로 빼기) + [가게 추가] → 고기·기준 선택 → **결론 카드**(추천 가게 + 이득 문장) → 표 → 시세 막대. 이득 문장 내용(D21)은 그대로, 위치만 위로. 표 머리에서 [빼기] 버튼을 없애고 칩으로 옮김.
- 정보 없는 핀 4종(정보 없음/필터 밖/중량 미표기/다른 메뉴만)은 **같은 점선 꼬리표**로 통일하고 글자로 구분. 범례에 "점선 = 가격 없음" 추가.
- 선택된 핀은 **남색 꼬리표**, 키보드 포커스는 숯불색 테두리로 모양을 나눔.
- 이 개편은 기획 시안(05-prototype)의 화면 구조와 다르다. 기획 문서(03)의 요구사항과 계산은 바뀌지 않음.
